# Sales-Dashboard

An interactive Tableau dashboard that transforms raw order, customer, product, and location data into a year-over-year view of sales performance and customer behaviour.

## Overview

This dashboard is designed to help stakeholders understand how sales are trending over time and how customer behavior changes across different segments, products, and locations.

## Key Insights

- Year-over-year sales comparison
- Regional and location-based sales performance
- Customer purchasing patterns
- Product and category contribution
- Revenue trends across time

## Features

- Interactive Tableau visuals
- Drill-down and filter capabilities
- Sales performance analysis by region and customer segment
- Clear comparison between current and previous periods

## Data Sources

The dashboard uses data related to:

- Orders
- Customers
- Products
- Locations

## Tools Used

- Tableau
- Structured business data sources

## How to Use

Open the Tableau workbook in Tableau Desktop to explore the dashboard and interact with the filters and charts.

## Purpose

The goal of this project is to turn raw sales data into a clear, actionable view of performance and customer behavior for easier decision-making.
